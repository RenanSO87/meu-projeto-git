# Boas Práticas para Git e GitHub

1. **Escreva mensagens de commit claras e descritivas:** Use frases no imperativo e forneça contexto sobre a mudança realizada.
2. **Utilize branches para organizar o trabalho:** Mantenha a branch principal estável e crie branches separadas para cada funcionalidade.
3. **Faça commits pequenos e frequentes:** Agrupe alterações relacionadas para facilitar revisões e manutenção do histórico.
